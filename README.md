# منظمة مشكاة للعمل الإنساني (Mishkat Humanitarian Aid System)

نظام هجين متكامل لإدارة الحالات والمساعدات الإنسانية والمتابعات الميدانية، مصمم خصيصاً ليعمل **100% بدون إنترنت (Offline-First)** مع المزامنة السحابية الذكية، ومتاح كـ **تطبيق لسطح المكتب (Windows Desktop)** وتطبيق للأجهزة الذكية **(Android & iOS)** ونسخة ويب تقدمية (**PWA**).

---

## 🌟 أبرز المزايا والقدرات

### 1. العمل الميداني الكامل بدون إنترنت (100% Offline-First)
* جميع العمليات (تسجيل الحالات، البحث الاجتماعي، المتابعات، الصرفيات، الإعدادات) تعمل بدون إنترنت عبر قاعدة بيانات محلية عالية الأداء (`Dexie / IndexedDB`).
* استجابة فائقة السرعة مع آلاف السجلات باستخدام العرض الافتراضي (`@tanstack/react-virtual`).
* توليد أكواد مؤقتة ميدانية مرتبطة بكود الجهاز (`CS-D1-0001`) مع تحويلها تلقائياً لأكواد رسمية متسلسلة عند المزامنة.

### 2. إدارة الموظفين والأدوار وكلمات السر محلياً (Local User & PIN Management)
* **إضافة موظفين جدد محلياً** وتعيين كلمات السر ورموز المرور (PIN) دون الحاجة للاتصال بالإنترنت.
* **تعديل وتغيير كلمات السر** بنقرة واحدة، مع إمكانية التوليد التلقائي للرموز العشوائية.
* **تجميد وتنشيط الحسابات** فورياً لحماية المنظومة.
* **حذف الموظفين** مع صمامات أمان تمنع حذف الحساب النشط الحالي أو آخر مدير نظام.
* **سجل تدقيق غير قابل للتلاعب (Audit Log)** يوثق كافة العمليات بدقة عالية.

### 3. توثيق الصرفيات وتتبع المساعدات (Tamper-Evident Receipts)
* توقيع إلكتروني حي للمستفيد على الشاشة (باللمس أو القلم أو الماوس).
* حساب بصمة أمان رقمية `SHA-256` ورمز استجابة سريع `QR Code` مطبوع على الإيصال.
* خصم فوري وتلقائي من مستودع المواد العينية والمخزون.

### 4. بوابة الداعمين المعزولة والخصوصية الصفرية (Zero-PII Donor Portal)
* لوحة تحكم تفاعلية وتقارير أثر دورية معزولة تماماً عن الأسماء والبيانات الشخصية الحساسة.
* تطبيق معيار **`Small-Cell Suppression`** لحماية العائلات في المناطق ذات الكثافة المحدودة.
* روابط مشاركة مؤقتة قابلة للإلغاء الفوري، مع أداة داخلية لطمس الوجوه وأرقام الهويات.

### 5. الاستيراد الذكي والنسخ الاحتياطي المشفر (AES-256-GCM)
* استيراد البيانات وترحيلها من ملفات Excel و CSV القديمة مع الحفاظ التام على الأصفار الأولى في الهويات والهواتف.
* استيراد وترحيل قواعد بيانات SQLite السابقة الخاصة بتطبيقات بايثون القديمة.
* تصدير واسترجاع نسخ احتياطية كاملة ومشفرة محلياً بكلمة مرور.

## 💻 التشغيل والتطوير المحلي

### المتطلبات الأساسية
* **Node.js**: الإصدار 18 أو أحدث
* **npm**: الإصدار 9 أو أحدث

### خطوات التشغيل السريع
```bash
# تثبيت الحزم البرمجية
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# تشغيل تطبيق سطح المكتب (Windows Electron)
npm run desktop

# تشغيل حزمة الاختبارات الآلية الشاملة (23 اختباراً)
npm test

# بناء حزمة الإنتاج
npm run build
```

## 📱 حزم الأجهزة الذكية وسطح المكتب

* **سطح المكتب (Windows)**:
  * تطبيق تنفيذي مستقل: `Mishkat-Aid.exe`
  * حزمة تثبيت رسمية: `Mishkat-Aid-Setup.exe`
* **أندرويد (Android)**:
  * مشروع كاباسيتور أصيل: `android/`
  * حزمة أندرويد موقعة: `Mishkat-Aid.apk`
* **آبل آيفون (Apple iOS)**:
  * مشروع Xcode أصيل: `ios/`
  * ملف تثبيت الويب كليب: `Mishkat-iOS-Install.mobileconfig`

## 🔒 الأمان وحماية البيانات
* تصميم متوافق مع معايير إمكانية الوصول **WCAG AA**.
* تطبيق مبدأ **العينين الأربعة (Four-Eyes Principle)** في الاعتماد المالي واعتماد الحالات.
* عزل صلاحيات الوصول على مستوى السجل والجدول (Row-Level Security).
* تشفير البيانات الحساسة وحمايتها محلياً وسحابياً.
